# Quick Start Guide

## For First-Time Users

### 1. Create Account
- Visit the app and sign up
- Verify your email
- You'll be taken to the setup wizard

### 2. Setup Wizard
Follow the 3-step wizard:
1. **Organization** - Name your organization
2. **Company Info** - Enter company details
3. **Preferences** - Set currency and language

### 3. Add Data
Start with:
- **Customers** (CRM module)
- **Products** (Inventory module)
- **Invoices** (Sales module)
- **Employees** (HR module)

### 4. Generate Reports
- Dashboard shows real-time metrics
- Analytics provides deep insights
- Export data as CSV/JSON

## Key Features

### Dashboard
- Real-time KPIs (revenue, customers, inventory, orders)
- AI-powered insights and forecasting
- Interactive charts and trends

### CRM
- Manage all customers
- Track lifetime value
- View customer history

### Sales
- Create and manage invoices
- Track payments (paid, pending, overdue)
- Generate revenue reports

### Inventory
- Real-time stock tracking
- Low stock alerts
- Reorder level management

### Accounting
- Transaction ledger
- Income vs expenses
- Profit calculations
- Multi-currency support

### HR
- Employee directory
- Payroll management
- Department tracking

### Analytics
- Advanced business metrics
- Customer acquisition trends
- Revenue forecasting
- AI-generated insights

## Tips & Tricks

1. **Bulk Import** - Use CSV export/import for quick data migration
2. **Organization Switching** - Create multiple organizations for different business units
3. **AI Reports** - Generate insights from dashboard with one click
4. **Mobile Access** - PWA enabled; add to home screen on mobile
5. **Data Export** - Always have backups; export monthly
