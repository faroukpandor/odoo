## Quick Launch Path (15 minutes)

### Step 1: Database Setup (5 min)
```
1. Go to https://app.supabase.com
2. Login → Select your project
3. Click SQL Editor
4. Run these 4 scripts in order:
   • scripts/001_create_erp_schema.sql
   • scripts/002_create_profiles_trigger.sql
   • scripts/003_seed_sample_data.sql
   • scripts/004_add_collaboration_tables.sql
```

### Step 2: Deploy to Vercel (5 min)
```
1. Go to https://vercel.com
2. Click "Add New Project"
3. Import your GitHub repo
4. Add 13 environment variables (from .env.example)
5. Click Deploy
```

### Step 3: Test (5 min)
```
1. Visit your production URL
2. Sign up → Dashboard
3. Test each module
4. Verify real-time sync
5. Check /api/health endpoint
```
